# Frame Problem

## Workflow
1. Read `wiki/index.md` and load only the pages bearing on the problem — usually `wiki/sintesi/` and the relevant `wiki/decisioni/` — then the brief, rubric, constraints, and existing problem documents.
2. Select one persona, blocked task, barrier, and intervention point.
3. Define the same scenario before and after with one measure.
4. Reject agentic behavior that a single fixed operation can solve.

## Required output
Create or update `docs/PROBLEM_FRAME.md`, then file what the framing settled: the binding choice as a page under `wiki/decisioni/`, what it did not settle in `wiki/domande-aperte.md`, and one appended line in `wiki/log.md`.

## Quality gate
Reject the result when it relies on static logs, hidden calculations, overlapping agent authority, an unbounded loop, or a non-blocking human gate.
