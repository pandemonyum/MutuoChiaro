# Frame Problem

## Workflow
1. Read the brief, rubric, constraints, and existing problem documents.
2. Select one persona, blocked task, barrier, and intervention point.
3. Define the same scenario before and after with one measure.
4. Reject agentic behavior that a single fixed operation can solve.

## Required output
Create or update `docs/PROBLEM_FRAME.md`.

## Quality gate
Reject the result when it relies on static logs, hidden calculations, overlapping agent authority, an unbounded loop, or a non-blocking human gate.
